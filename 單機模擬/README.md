# SAM／REN／JEFF 單機模擬操作卡

這套程式讓三人在各自 Windows 電腦從**完整 LLM_PJ 專案目錄**雙擊一個檔案，建立私有 Python 環境、執行 12 項本機預檢，並開啟 `127.0.0.1` 隔離網站。第一次執行需要 Python 3.11～3.14 x64 與網路安裝公開 Python 套件；之後重用 `%LOCALAPPDATA%\VibeCart\SRJLocalSimulation\venv`。程式不讀 `.env`、不連 Atlas、不啟用付費模型；三個帳號每次隨機產生的密碼只顯示在本機視窗，絕不放進郵件或 GitHub。關閉視窗或 Ctrl+C 停止網站，記憶體資料隨之消失。

| 操作者 | 雙擊檔案 | 本機演練路線 |
| --- | --- | --- |
| SAM | `Start-SAM.cmd` | 用本機 SAM 帳號登入後台，確認角色允許；以 REN 帳號核對後台拒絕。檢查首頁、商品、購物車、規則退回與離線簡報。 |
| REN | `Start-REN.cmd` | 用本機 REN 帳號登入／登出，兩個瀏覽器視窗模擬裝置；確認後台拒絕、商品規格、數量錯誤、購物車與不收款示範訂單。 |
| JEFF | `Start-JEFF.cmd` | 用本機 JEFF 帳號檢查後台、Local 推薦／雲端洞察／AI 比較的關閉或規則退回狀態；核對 S06～S08 與簡報。 |

每個人可開另一個瀏覽器視窗輸入本機網址與自己的**本次**帳密；不要把此密碼用於正式站。先把瀏覽器縮為 390×844，再測 844×390，記錄 URL、時間、視窗寬度、預期／實際、是否橫向溢出與去敏畫面。這是**電腦尺寸模擬**，沒有手機原生鍵盤、觸控、實際斷網或投影。

預檢報告位於 `%LOCALAPPDATA%\VibeCart\SRJLocalSimulation\reports`，只有檢查結果、角色、時間與本機電腦名稱，不含密碼。請把報告及逐項結果交回[具名接收表](../專題進度/2026-10-19_具名接收與異機復原表.md)的「模擬技術子項」，**不得寫入**三人的本人簽收欄。若需要 REN 的真三節點交易故障演練，另在具有 `mongod.exe` 的隔離機器依 `scripts/run_local_checkout_fault_matrix.py --help` 執行；這套 `mongomock` 網站沒有真正的 MongoDB 交易，不能把示範訂單當 R2／R3 完整通過。REN 異機復原仍依 [N14 操作卡](../docs/N14_REN_異機復原_2026-10-19.md)使用兩支 USB，沒有內建金鑰。

各項與模擬範圍的對照：

| 原項目 | 單機可執行部分 | 仍須另外完成的原條件 |
| --- | --- | --- |
| S1／R1 | 本機角色登入、登出、後台拒絕；自動預檢角色政策 | 正式帳號、雙實體裝置及撤權後舊 cookie |
| S2 | 電腦 390×844／844×390 畫面、商品價格庫存、表單錯誤、購物車 | 實際手機、原生鍵盤／旋轉與正式站撤權 |
| S3／S4 | 參照 GitHub／既有部署與 NAT 證據做唯讀對照 | 正式同版 revision、所有 consumer、流量切換／回退 |
| S5／R2／R3 | `mongomock` 購物流程；有 mongod 可加跑本機隔離故障矩陣 | 真遠端資料庫故障、交易途中撤權、快照／回滾與清理 |
| S6／J3 | 本機開 V5 PPTX／PDF、核 S01～S12 圖與頁碼 | 實際斷網、投影、計時與本人覆核 |
| R4／R5 | 預備兩支 USB、核密文檔案／操作卡 | REN 在異機電腦解密、還原、報告及清理 |
| J1／J2 | 本機後台／AI 關閉狀態與 synthetic 隔離文件覆核 | JEFF 本人在正式同版服務與所有 consumer 驗證 |

三人完成各自演練後，以「已做／失敗／未做」逐列交回，不因共同 12/12 預檢或同機畫面就宣稱原 S1～S6、R1～R5、J1～J3 已正式簽收。若只要確認能啟動，不開瀏覽器，可在 PowerShell 執行 `powershell -NoProfile -File .\單機模擬\Start-SRJ.ps1 -Role SAM -PreflightOnly`（其他人改角色）。
