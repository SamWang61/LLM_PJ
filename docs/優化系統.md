# 優化系統

本文件記錄 VibeCart 的操作優化與系統 Debug，供組員核對調整原因、實際行為及驗證結果。首項優化依 JEFF 與 SAM 意見，取消登出前的第二次確認，讓前台會員與後台管理員按一次「登出」即可結束目前裝置的登入。

English summary: Storefront and admin navigation now submit logout directly, with no confirmation page. CSRF validation and per-device session revocation remain in place.

## 優化紀錄

| 編號 | 日期（台灣時間） | 項目 | 原因與決定 |
| --- | --- | --- | --- |
| OPT-001 | 2026-10-21 | 移除登出二次確認 | JEFF 與 SAM 認為再次確認屬過度審核，改為按一次即登出。 |

## OPT-001 登出流程

| 操作 | 調整前 | 調整後 |
| --- | --- | --- |
| 商城導覽列按「登出」 | 開啟確認頁，再按「確認登出」 | 立即登出並返回商城首頁 |
| 後台帳號列按「登出」 | 同樣先進入確認頁 | 立即登出並返回商城首頁 |
| 完成提示 | 完成後顯示「您已安全登出。」 | 保留原有完成提示 |

前台與後台共用一份登出表單，使用原生 HTML 提交，不依賴 JavaScript，也沒有額外確認視窗。按鈕保留導覽列的外觀及鍵盤焦點樣式。

### Session 與請求處理

登出表單直接向 `POST /auth/logout` 提交同一登入 Session 的 CSRF token。缺少或錯誤的 token 仍回應 HTTP 400；移除的是畫面上的重複確認步驟。

v4 模式沿用目前裝置的伺服器 Session 撤銷與瀏覽器 Session 清除，因此舊 Cookie 不能重放登入；同帳號其他裝置維持登入。登出不更動購物車、訂單或帳號資料，也不執行全裝置登出。

原確認頁已移除，`GET /auth/logout` 現回應 HTTP 405，避免連結預覽或預先載入觸發登出。既有書籤或舊頁面須重新開啟商城，再使用新版「登出」按鈕。相關驗證工具改從商城導覽列的登出表單取得 token，須搭配本版部署使用；AI 洞察探針明確選取提問表單，避免誤選新增的導覽列表單。

### 驗證方式

自動測試從實際渲染的導覽列表單取得 token 並提交一次，核對商城會員、商城管理員及後台管理員均直接回到首頁，顯示完成提示，且不出現確認頁。另驗證錯誤 token 不會登出、舊 Cookie 失效，以及其他裝置仍可存取購物車。

GitHub 交付、CI 與正式站部署分開記錄；本項修正的推送不代表正式站已切換新版。
