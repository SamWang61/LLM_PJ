LLM_PJ Daily Backup

這是 SAM 管理的個人桌面備份工具，用於將 LLM_PJ 專案資料備份至指定 Google Drive 目錄，保留既有檔案與共用連結。

工具讀取指定目錄的檔案及權限，先保存並暫停共用，再同步一般檔案、加密機密內容。雲端清冊、大小、雜湊與復原驗證全部通過後，才恢復原共用；失敗時保留恢復紀錄並維持停止共用。

OAuth 授權憑證與解密金鑰只保存在管理者的本機私有區域，不放入 GitHub 或共用備份。這個網站僅提供工具說明，不提供登入或上傳功能。

A personal desktop backup tool for the LLM_PJ learning project. It preserves fixed Drive identities, encrypts confidential content, and restores sharing only after complete verification. Credentials and encryption keys remain local.
