# 協作守則 / Code of conduct

尊重不同經驗與觀點，以具體證據討論程式和設計；避免人身攻擊、騷擾與公開他人個資。Respect different experience levels, discuss code with evidence, and avoid harassment or disclosure of personal information.

遇到衝突，請透過既有私下管道聯繫 SamWang61，由維護者依情況處理留言與參與權限。Report conflicts privately to SamWang61; maintainers may moderate discussions and participation.
