# 集合與索引建置

狀態：13 集合與 23 個自訂索引已由 bootstrap_schema.py 透過 PyMongo 實際建立並讀回驗證；13 個 strict/error validators 亦已套用。此文件中的 mongosh 區塊保留為等價索引範例，該區塊本身未執行；以 05_實際Schema與索引.md 為實際結果。未遷移舊資料或匯入 Seed。

## 13 個目標集合

## 23 個自訂索引

各集合 MongoDB 自建 `_id_`；以下不計入 `_id_`，新環境合计 36 個索引。

```javascript
// mongosh 範例，尚未執行。
// 執行前先確認連到正確 Cluster，並完成備份、重複值及現有索引檢查。
// 只對確認過的目標 DB 操作；不刪除或覆蓋任何既有索引。
const target = db.getSiblingDB('vibecart_ai');
const names = [
  'users', 'categories', 'products', 'carts', 'orders', 'user_events',
  'ai_requests', 'product_embeddings', 'recommendations', 'ai_insights',
  'ai_usage', 'request_limits', 'schema_migrations'
];
const existing = new Set(target.getCollectionNames());
for (const name of names) {
  if (!existing.has(name)) target.createCollection(name);
}

target.users.createIndex({email: 1}, {name: 'uq_users_email', unique: true});
target.users.createIndex({firebase_uid: 1}, {
  name: 'uq_users_firebase_uid', unique: true,
  partialFilterExpression: {firebase_uid: {$type: 'string'}}
});
target.categories.createIndex({name: 1}, {name: 'uq_categories_name', unique: true});
target.categories.createIndex({slug: 1}, {name: 'uq_categories_slug', unique: true});
target.products.createIndex({sku: 1}, {name: 'uq_products_sku', unique: true});
target.products.createIndex({category_id: 1, is_active: 1}, {
  name: 'idx_products_category_id_is_active'
});
target.products.createIndex({name: 'text', description: 'text'}, {
  name: 'idx_products_name_description_text', default_language: 'none'
});
target.carts.createIndex({user_id: 1}, {name: 'uq_carts_user_id', unique: true});
target.orders.createIndex({order_number: 1}, {name: 'uq_orders_order_number', unique: true});
target.orders.createIndex({user_id: 1, checkout_id: 1}, {
  name: 'uq_orders_user_id_checkout_id', unique: true
});
target.orders.createIndex({user_id: 1, created_at: -1}, {
  name: 'idx_orders_user_id_created_at'
});
target.orders.createIndex({is_demo: 1, payment_status: 1, created_at: -1}, {
  name: 'idx_orders_is_demo_payment_status_created_at'
});
target.orders.createIndex({status: 1, created_at: -1}, {
  name: 'idx_orders_status_created_at'
});
target.user_events.createIndex({event_id: 1}, {name: 'uq_user_events_event_id', unique: true});
target.user_events.createIndex({order_id: 1}, {
  name: 'uq_user_events_order_id_purchase', unique: true,
  partialFilterExpression: {event_type: 'purchase', order_id: {$type: 'objectId'}}
});
target.user_events.createIndex({user_id: 1, event_type: 1, created_at: -1}, {
  name: 'idx_user_events_user_id_event_type_created_at'
});
target.user_events.createIndex({recommendation_id: 1, event_type: 1}, {
  name: 'idx_user_events_recommendation_id_event_type'
});
target.product_embeddings.createIndex({product_id: 1, model: 1}, {
  name: 'uq_product_embeddings_product_id_model', unique: true
});
target.recommendations.createIndex({user_id: 1, created_at: -1}, {
  name: 'idx_recommendations_user_id_created_at'
});
target.ai_requests.createIndex({task_type: 1, actual_provider: 1, created_at: -1}, {
  name: 'idx_ai_requests_task_type_actual_provider_created_at'
});
target.ai_requests.createIndex({parent_request_id: 1}, {
  name: 'idx_ai_requests_parent_request_id'
});
target.ai_insights.createIndex({expires_at: 1}, {
  name: 'ttl_ai_insights_expires_at', expireAfterSeconds: 0
});
target.request_limits.createIndex({expires_at: 1}, {
  name: 'ttl_request_limits_expires_at', expireAfterSeconds: 0
});

// 讀回核對，不以 createIndex 沒拋錯作為全部驗收結果。
for (const name of names) {
  printjson({collection: name, indexes: target.getCollection(name).getIndexes()});
}
```

`default_language=none` 是本文件對中文商品文字的實作選擇，停用預設英文詞幹處理；不保證中文斷詞或語意搜尋效果，仍需實測。

此範例在乾淨環境可建立集合與索引；它不是完整遷移工具。同鍵不同名稱／選項、既有 text 索引、重複值會需要先處理；不得直接刪除索引或資料來消除錯誤。建置不是整批原子操作，部分成功後應讀回現況再續做，不能將遷移紀錄直接標成功。

## 驗證要點

- email 寫入前去空白並小寫，SKU 去空白並大寫；索引不負責正規化。
- users.firebase_uid 只對 String 唯一，允許多筆 null。
- user_events.order_id 只對 purchase 且 ObjectId 唯一，不限制其他類型事件共用訂單關聯。
- orders 的 user_id＋checkout_id 唯一不等於完整冪等，仍需比對 request_hash。
- TTL 只有兩個 expires_at 索引，expireAfterSeconds 必須為 0；欄位是 BSON Date。ai_usage、user_events、ai_requests 不加 TTL。
- 建索引前以 getIndexes 與重複鍵聚合檢查既有環境；validator 用 listCollections 讀回 options.validator、validationLevel、validationAction。
- 來源已有舊集合時保留，完成對照及資料驗收後才另行退役；不以僅有 13 集合當成刪除旧集合的理由。
