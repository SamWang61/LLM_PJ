# 2026-10-05 Schema 重建與超市商品匯入

依使用者明確指示，對指定 `vibecart-ai-free` Cluster 的 `vibecart_ai` 重建專案 Schema，並重新匯入已整理完成的超市商品。重建前確認目標為 0 個集合，未刪除或覆蓋任何既有業務資料。

## 建置結果

|項目|結果|
|---|---|
|Schema|Complete Schema v4；19 個核心集合加 8 個保留集合，共 27 個|
|驗證規則|全部 27 個集合均為 strict / error|

每项商品包含原來源名稱、自行改寫摘要、規格、擷取時的參考價格、照片網址、商品頁連結。商品名稱與商品頁皆為 336 個不同項目；規格文字共 256 種。來源照片僅記錄網址，不複製圖片檔。

庫存為明示的教學模擬值，價格不是即時報價；評價使用 DEFAULT 4.0 且無真實評價筆數。商品使用穩定的 `CF-` 代碼、SKU 使用 `CF-SKU-`，匯入僅執行 insert-only upsert，不重設已存在的庫存或其他編輯。

## 執行及驗證

1. 透過 PyMongo 確认 host 與 DB，並確認空環境。
2. 依序執行 bootstrap_schema.py、migrate_cart_v3.py、migrate_schema_audit.py、migrate_complete_v4.py；每階段均讀回驗證。
3. 以 import_catalog.py --apply 在交易內提交 832 筆商品相關文件（32 分類＋128 品牌＋336 商品＋336 SKU）。
4. Flask 直接連真實 Atlas，匿名唯讀核對全部 336 項、14 頁、8 大類篩選、24 小類篩選、24 個代表商品詳情、來源／照片連結及關鍵字搜尋。
5. verify_recovery.py 逐筆比對匯入文件的完整 BSON 內容，核對分類與 SKU 參照，並再次讀回全部集合、validator、索引與遷移狀態。最新結果以以下 JSON 為準。
