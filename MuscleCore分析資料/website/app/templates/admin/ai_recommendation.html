為什麼用本機模型

  • BGE 把商品名稱、分類、摘要、描述與標籤轉成向量，用 cosine 相似度找出語意相近的商品；不會生成文字。
  • 推論在本機 CPU 執行，商品資料不送到外部 API，也沒有 API 費用。
  • 模型下載後推論不需網路；但網站讀取 Atlas 資料與遠端商品圖片仍需要網路。
  • 向量依商品文字快取在記憶體；商品文字變更時會自動重新計算，「更新商品向量」會清除快取並全部重算。
