# 版面與素材規範

## 視覺方向

選用「超市編輯式版面＋AI 技術圖解」自訂版型。超市網購以真實商品介面及自然食材色彩表達，AI 系統以深藍底、青綠連線與清楚的資料流表達。沒有可用的模板選擇器，因此直接依使用者指定的題材設計。

| 元素 | 規格 |
|---|---|
| 畫布 | 16:9，1280×720，等比例匯出 PowerPoint |
| 底色 | 奶油白 #F6F5EF |
| 主色 | 超市綠 #14634B |
| 技術頁 | 深藍 #122D3A，青綠 #38C5CD |
| 字體 | Microsoft JhengHei／微軟正黑體 |
| 標題 | 一般頁 44 px，約 33 pt；封面主標 74 px |
| 內文 | 通常 26～28 px；避免長段落 |
| 頁邊距 | 左右 64 px |
| 表格與圖解 | 原生可編輯物件，文字可在 PowerPoint 修改 |
| 截圖 | 保留原始比例及完整內容，不重畫成假操作圖 |

## 封面與封底

封面左側安排專題名稱、班別與團隊資訊，右上為超市購物籃與 AI 連線概念圖，右下放入使用者提供的合照。封底以合照原圖滿版鋪底，使用白色 84% 不透明遮罩，使影像以約 16% 視覺強度作為浮水印。照片與遮罩都是獨立 PowerPoint 物件，未修改照片原始檔。

封面及封底都列組員學號、中文姓名、英文名、Email 與講師資料。完整資料見 README。

## 逐頁版型

1. 封面：左文右圖與團隊合照。
2. 情境：左側使用者需求，右側商品介面實拍。
3. 架構：深藍底可編輯模組及連線。
4. 資料：大數字與資料關聯表。
5. 商品：左側搜尋／SKU 說明，右側商品原圖。
6. 會員：登入入口原圖搭配驗證重點。
7. 購物：原生可編輯流程與一致性機制。
8. 推薦：深藍技術頁，區分規則與模型狀態。
9. 後台：可編輯 KPI 定義表，不填虛構營收。
10. AI：可編輯方法比較表，不填未量測的延遲與成本。
11. 驗證：本機測試與 D4 結果，搭配窄視窗圖片及範圍說明。
12. 下一階段：AI 啟用、D5 維護與稽核、金流／物流提案，並區分交付前驗收。
13. 封底：滿版合照浮水印、成果、後續與聯絡方式。

## 圖像來源

- 團隊合照：使用者提供的「照片 1.jpg」，原圖完整保留。
- 操作截圖：GitHub 固定來源提交內的原始 PNG。
- 封面超市概念圖：使用內建 image_gen 生成，提示詞見 assets/image-generation-prompt.txt；不作系統驗收證據。
